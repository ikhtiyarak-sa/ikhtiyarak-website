# اختيارك — النسخة الثانية
موقع عربي ثابت لشتاء السعودية. ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع GitHub.

## قبل الإطلاق التجاري
- استبدل روابط البحث العامة بروابط عمولة خاصة بعد الموافقة في البرنامج.
- احصل على صور المنتجات عبر الوسائل المصرح بها من كل برنامج شراكة؛ الصور الحالية فوتوغرافية توضيحية من Unsplash وليست صور منتجات المتاجر.
- تحقق من حقوق إعادة استخدام كل صورة وأضف نسبتها إن كانت مطلوبة؛ لا تنسخ صور المتاجر مباشرة.
- أضف بريد تواصل حقيقي وسياسة خصوصية بحسب أدوات التتبع التي ستفعّلها.
- أضف اسم النطاق إلى Search Console وأنشئ sitemap بعد معرفة الرابط النهائي.
- لا توجد أسعار أو خصومات مزعومة أو روابط عمولة مفعلة في النسخة الحالية.
